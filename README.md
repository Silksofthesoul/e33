# E33 — Mimi Markov

Эксперимент с цепями Маркова первого порядка. Самостоятельное SPA на HTML, CSS и JavaScript: обучение, генерация и хранение данных происходят в браузере пользователя.

## Запуск

В корне скачанного проекта:

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Откройте http://localhost:8080/.

## Использование и данные

1. Введите текст и нажмите «Обучить и создать». Каждый новый текст дополняет личную модель, повтор того же целого текста не учитывается снова.
2. «Ещё вариант» создаёт новую последовательность из 65 слов.
3. Текст в поле сохраняется автоматически; модель сохраняется после обучения. Обновление страницы восстанавливает их.
4. «Очистить мои данные» после подтверждения удаляет только ключ этого эксперимента.

Ключ localStorage: `silksofthesoul:mimi-markov:spa:v1`. Он хранит текущий текст, версию формата, слова, переходы, частоты и хеши обученных текстов. Полная история исходных документов отдельно не архивируется. Серверный корпус не импортируется: первый запуск начинается с пустой модели.

Данные не отправляются в сеть. В приложении нет fetch/XHR, телеметрии, CDN и POST-маршрутов; CSP запрещает сетевые соединения скриптов. Это не шифрование: localStorage доступен другим скриптам того же origin. Для изоляции от других экспериментов используйте отдельный origin. Origin включает протокол, имя хоста и порт; смена одного из них создаст другое хранилище. Данные не синхронизируются между устройствами. Очистка данных сайта или завершение приватной сессии может удалить их.

При запрете доступа к localStorage приложение явно сообщает, что работает только в памяти текущей вкладки. При переполнении хранилища прежняя сохранённая модель не заменяется, а введённый текст остаётся в поле. Повреждённые или неизвестные версии данных не перезаписываются автоматически.

## Язык интерфейса

Поддерживаются те же шесть языков, что и на Silksofthesoul: русский, английский, испанский, французский, упрощённый китайский и японский. Переводятся подписи, placeholders, кнопки, справка, диалог очистки, счётчики, статусы и ошибки.

В iframe на том же origin E33 читает текущий язык родительской страницы (`document.documentElement.dataset.locale`, затем `lang`) и подписывается на существующее событие `site:languagechange` с `detail.locale`. Смена языка обновляет только интерфейс, без перезагрузки iframe, изменения текста, результата или обученной модели. После восстановления страницы из browser back/forward cache подписка восстанавливается. Изменять frontend сайта для этой интеграции не требуется.

При самостоятельном запуске приоритет: `?lang=en` или языковой префикс URL → сохранённый выбор сайта `silksofthesoul:language` → языки браузера → en для .com / ru для остальных адресов. Региональные теги (`en-GB`, `zh-Hans-CN`) приводятся к поддерживаемому языку. Недоступный родительский frame и запрещённый localStorage не мешают запуску. Для iframe другого origin язык хоста автоматически не читается: используйте `?lang=` при открытии такого демо.

Данные, введённые пользователем, и сгенерированный текст не переводятся. Токенизация и алгоритм остаются прежними. Словари находятся в `assets/messages.js`, адаптер сайта — в `assets/i18n.js`; общих runtime-зависимостей с сайтом нет. Для обновления Preview нужно получить новую версию E33 и повторно упаковать artifacts; allowlist в preview.json включает оба новых файла.

## Условия использования исходников

Автор — Silksofthesoul. Отдельная лицензия пока не выбрана; публичная доступность исходников сама по себе не заменяет лицензию.
